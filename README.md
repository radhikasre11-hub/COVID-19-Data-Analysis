# COVID-19 Data Analysis and Visualization

## Project Overview
This project analyzes COVID-19 data across countries and examines daily case trends in India using Python.

## Objectives
- Load and clean COVID-19 datasets.
- Identify the top 10 countries by confirmed cases.
- Analyze India's confirmed cases, deaths, and recoveries.
- Visualize India's daily COVID-19 cases.
- Calculate a seven-day rolling average.
- Compare India, the USA, and China.

## Technologies
- Python
- Pandas
- Matplotlib

## Dataset Files
- `Data/country_wise_latest.csv`
- `Data/full_grouped.csv`

## Generated Visualizations
- `charts/top_10_countries.png`
- `charts/india_daily_cases.png`
- `charts/india_rolling_average.png`
- `charts/country_comparison.png`

## How to Run
1. Install the dependencies using `python -m pip install pandas matplotlib`.
2. Open the project folder in VS Code.
3. Run `python covid_analysis.py`.

## Conclusion
The project demonstrates data cleaning, exploratory data analysis, and visualization techniques using public-health data. Results depend on the supplied dataset and its reporting coverage.
